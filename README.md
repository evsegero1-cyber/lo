# LIFE OS

Персональная офлайн-система здорового образа жизни: вода, питание, сон, вес и тело, тренировки, полезные и вредные привычки, самочувствие, гигиена, здоровье, цели, аналитика.

- Полностью офлайн: без регистрации, серверов, облака и ИИ.
- Данные — только на устройстве (IndexedDB внутри приложения). Резервные копии JSON, экспорт CSV.
- Личный день начинается с пробуждения, а не с полуночи — рассчитано на ночные смены.

## Как получить APK

1. Создайте на GitHub новый репозиторий, например `LifeOS`.
2. Загрузите в него **содержимое** этого архива (папки `www`, `scripts`, `tests`, `android-res`, `.github` и файлы из корня). Папка `.github` обязательна — в ней сборка.
3. Откройте вкладку **Actions** → «Сборка APK». Сборка запускается сама после загрузки (или кнопкой *Run workflow*).
4. Через 5–8 минут в завершённой сборке внизу появится артефакт **LIFE-OS-apk** — скачайте, распакуйте и установите `LIFE-OS.apk`.

Если в настройках репозитория включить *Settings → Pages → Source: GitHub Actions*, появится и веб-версия (работает офлайн после первого открытия).

> Обновление APK поверх старого сохраняет данные. Удаление приложения удаляет данные — перед этим сделайте резервную копию (Настройки → Данные).

## Разработка

```
npm install
npm test          # тесты расчётов (личный день, питание, сон, привычки, напоминания)
npm run build     # копирует мост Capacitor и пересобирает service worker
python3 -m http.server --directory www   # открыть в браузере
```

Устройство кода — в [ARCHITECTURE.md](ARCHITECTURE.md).
